# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short: be respectful, assume good faith, and keep discussion focused on the work. Harassment,
personal attacks and demeaning comments are not welcome here.

## A note specific to this project

This is offensive-security tooling. Discussion of reconnaissance techniques is on topic;
soliciting help attacking systems you are not authorised to test is not, and such issues will be
closed.

## Reporting

Report unacceptable behaviour to the maintainer via
[a private security advisory](https://github.com/aqhmal/securitytrails-mcp/security/advisories/new)
or by direct message on [GitHub](https://github.com/aqhmal). Reports are handled confidentially.
